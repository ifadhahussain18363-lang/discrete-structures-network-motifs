# Person 4 deliverables

This folder contains:
- `department_triad_motif_z_scores.png`: the completed grouped bar chart.
- `plot_motifs.py`: Python script to regenerate the chart from the project's existing CSV files.
- `T7_T8_findings.md`: interpretation of the results.

To use the script, copy `plot_motifs.py` into the project's `src/` folder and run it from the project root with:
`python src/plot_motifs.py`

Install the two dependencies if needed:
`pip install pandas matplotlib`
