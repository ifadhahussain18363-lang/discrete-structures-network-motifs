\### Hand-Worked Example of Triad Classification



Consider three nodes A, B, and C. Node A sends emails to both B and C. There are no other directed connections among these three nodes.



Using the six-bit encoding order:



1\. A → B = 1

2\. A → C = 1

3\. B → A = 0

4\. B → C = 0

5\. C → A = 0

6\. C → B = 0



The resulting binary code is \*\*000011\*\*, which is equal to decimal 3.



The canonical code is 3, and according to our classification dictionary, it belongs to \*\*Triad Class 1\*\*.



Therefore, this example represents a connected directed triad of Class 1.
